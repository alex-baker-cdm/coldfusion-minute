# CRUD Demo Application

Example of building CRUD apps with CFML and the [Framework One (FW/1)](https://github.com/framework-one/fw1) framework.

## Requirements

- **Adobe ColdFusion 2023** (LTS) or **Lucee 6.x** (latest stable)
- MySQL database with a datasource named `test`

## Features

- Full user management CRUD (Create, Read, Update, Delete)
- MVC architecture with FW/1
- Dependency injection via FW/1's IOC container
- Pagination and search
- Bootstrap-based UI with custom tags
