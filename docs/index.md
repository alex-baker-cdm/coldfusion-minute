# Documentation

## coldfusion-minute

A collection of practical CFML examples targeting **Adobe ColdFusion 2023** (LTS) and **Lucee 6** (latest stable).

### Supported CFML Engines

| Engine                  | Minimum Version | Status       |
| ----------------------- | --------------- | ------------ |
| Lucee                   | 6.0.0           | Recommended  |
| Adobe ColdFusion        | 2023.0.0        | Supported    |

### Java Requirements

Both Lucee 6 and Adobe ColdFusion 2023 require **Java 11** or later. Java 17 LTS is recommended for production use.

### Development Setup

Install [CommandBox](https://www.ortussolutions.com/products/commandbox) and run:

```bash
box server start
```

See the [README](../README.md) for full setup instructions.
